# 观众研究隐私治理服务

面向博物馆观众研究同意、数据集谱系和披露控制的 TypeScript 后端服务。

服务在任何新导出发生前核对**研究目的、数据来源、同意范围、保留期限、可访问角色与随机参与标识**，只交付当前项目方案允许的最小字段，并在去重样本低于披露阈值时拒绝出库。方案版本升级会重新判断既有同意是否覆盖；观众撤回后可定位记录进入删除或不可逆匿名化流程，下游使用方收到处置事项，并留下不含个人数据的合规证明（hash 链账本，仅含 HMAC 指纹与计数）。已撤回身份进入墓碑，离线传感器补传命中即丢弃，身份不可重建。保护负责人可从任一数据集反查其合法来源、到期动作与全部下游去向。

## 运行

需要 Node.js 22 或更高版本。执行 `npm ci` 安装依赖，`npm test` 完成编译与测试，`npm start` 启动已编译服务。服务默认监听 8000 端口，访问 `GET /health` 可确认进程状态。也可以使用 `docker compose up --build` 启动容器。

环境变量：

- `PORT` / `HOST`：监听地址，默认 `0.0.0.0:8000`。
- `GOVERNANCE_SECRET`：HMAC 密钥。**生产必须固定**，否则重启后指纹与撤回墓碑无法对账。
- `DATA_DIR`：状态快照目录，默认 `.runtime/`（每次变更后写入 `state.json`，启动时自动恢复）。

## API 概览

| 方法与路径 | 说明 |
| --- | --- |
| `POST /protocols` | 注册研究方案版本；版本升级自动重估既有同意覆盖 |
| `POST /consents` | 登记同意（目的、覆盖版本、保留期、受限字段白名单） |
| `POST /consents/withdrawals` | 撤回同意：删除/匿名化可定位记录，派发下游处置事项，出合规证明 |
| `POST /datasets` | 注册数据集（来源、上游谱系、到期动作、保留期） |
| `POST /records` | 采集/补传记录；命中撤回墓碑返回 `identity_retired` 且不入库 |
| `POST /exports/evaluate` | 出库预评估（dry-run），返回全部拒绝原因与最小化字段 |
| `POST /exports` | 执行出库：通过则 `201` 返回最小字段行，否则 `422` 返回决策 |
| `GET /datasets/:id/lineage` | 谱系反查：来源链、到期动作、全部下游去向 |
| `GET /disposal-tasks?consumerId=` | 下游处置事项清单 |
| `POST /disposal-tasks/:id/complete` | 使用方确认处置完成 |
| `POST /maintenance/expiry-sweep` | 到期清扫：按登记的到期动作处置过期同意/记录/数据集 |
| `GET /compliance/proofs` | 合规证明（不含个人数据） |
| `GET /audit` | 完整审计账本（hash 链） |

## 设计要点

- **随机参与标识**：业务记录只允许 `pt_` 前缀的伪匿名标识；直接标识符字段（姓名、人脸模板等）在全局黑名单中，即使方案误配也不出库。
- **最小字段交付**：交付字段 = 申请字段 ∩ 方案 fieldPolicy − 全局黑名单；未指定字段时按方案策略交付。
- **披露阈值**：按去重参与者计数，低于方案阈值即拒绝出库。
- **版本化同意**：同意记录声明覆盖的方案版本；版本升级后未覆盖的同意自动被出库闸门排除，重估结果以指纹清单形式留痕。
- **不可逆匿名化**：切断参与标识链接（不保留映射）、移除准标识符、时间泛化到天。
- **撤回墓碑**：撤回后参与标识的 HMAC 指纹进入墓碑，迟到补传（如离线传感器）命中即丢弃并留审计，身份不可重建；重新参与须使用新标识。
- **合规证明**：账本条目只含 HMAC 指纹与计数，hash 链防篡改，可直接对外出示。

`reference/domain.json` 保存公开的同意状态、数据来源和到期动作枚举，代码枚举由其守护同步（见 `tests/reference-sync.test.ts`）。
