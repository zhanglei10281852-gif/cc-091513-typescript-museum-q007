# 领域说明

观众研究数据来自问卷、传感器和派生数据集，每项使用应受研究目的、同意范围、保留期限与访问角色约束。撤回同意需要传播到仍可定位的下游记录。

`reference/domain.json` 保存公开的同意状态、数据来源和到期动作枚举。正式业务记录应使用随机参与标识，并保留方案版本和下游使用关系。

## 关键概念

- **随机参与标识（participantId）**：采集侧使用的假名标识。服务内部以其定位记录；对外（审计、处置通知、合规证明、谱系）只出现其密钥散列定位子（participantLocator）。
- **方案版本（protocolVersion）**：研究方案的每次变更登记为新版本。同意绑定版本；版本变化时重估既有同意是否仍覆盖新范围，不覆盖则转入 `restricted`，重新同意前不得导出。
- **披露阈值（disclosureThreshold）**：导出候选集中去重参与者低于阈值即拒绝出库。
- **最小字段交付**：交付字段 = 请求字段 ∩ 项目可交付字段 − 直接标识符；导出行以按数据集重键控的假名键（participantKey）标识参与者。
- **撤回墓碑（tombstone）**：撤回后登记，迟到的离线补传命中墓碑即丢弃，不得重建已撤回身份；参与者重新同意后墓碑解除。
- **处置事项（dispositionNotice）**：撤回传播到受影响数据集（含派生子孙）的全部下游消费者；直接导出要求清除该参与者行，派生数据集要求销毁。
- **合规证明（complianceProof）**：只含计数、数据集/通知标识与定位子，不含个人数据；附出具时的审计链头哈希。
- **审计链（auditLog）**：追加式哈希链，写入时强制校验不得包含个人数据字段，可随时重放验证。
